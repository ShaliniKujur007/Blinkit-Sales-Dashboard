# Blinkit Sales Dashboard 📊

## 📌 Project Overview

The **Blinkit Sales Dashboard** is an interactive **Power BI** project designed to analyze sales performance and identify key business insights from Blinkit's sales data.

The dashboard provides a comprehensive view of **total sales, item quantities, customer ratings, outlet performance, product categories, and sales trends**, helping users understand business performance through interactive visualizations and filters.

## 🎯 Objectives

* Analyze overall sales performance and revenue trends.
* Track total items sold and customer ratings.
* Compare sales across different outlet types and locations.
* Identify top-performing product categories.
* Understand sales patterns based on product characteristics.
* Provide an interactive dashboard for quick and effective analysis.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated metrics
* **Data Visualization** – Charts, KPIs, tables, and interactive filters

## 📊 Dashboard Features

The dashboard includes:

* **Total Sales**
* **Number of Items Sold**
* **Average Customer Rating**
* **Outlet-wise Sales Analysis**
* **Product Category Analysis**
* **Outlet Type Comparison**
* **Location-wise Performance**
* **Sales Trend Analysis**
* Interactive slicers and filters for dynamic analysis

## 🔍 Key Insights

The dashboard helps identify:

* High-performing product categories
* Sales contribution of different outlet types
* Variations in sales across locations
* Customer rating patterns
* Products and outlets contributing significantly to overall sales
* Overall sales trends and business performance

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Microsoft Power BI Desktop**.
3. Use the available filters and slicers to interact with the dashboard.
4. Explore sales, product, outlet, and customer-related insights.
